# ⚔️ Git Conflict Resolution Exercise

This repository contains a hands-on **Git conflict resolution** practice.  
The main purpose of this repo is to simulate merge conflicts and learn how to resolve them effectively using Git tools.

## 🧠 What You'll Learn

- How merge conflicts occur
- How to identify and resolve them
- Best practices for conflict management

Thanks for visiting this repository!  
Feel free to fork, test, and practice with it.
